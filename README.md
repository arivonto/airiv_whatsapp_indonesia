# Indonesia WhatsApp Business Messaging Engine (Fonnte & WAHA Sandbox)

Automated WhatsApp Notifications for Orders, Invoices, Biteship Resi, and Payslips with Fonnte & Sandbox

## Odoo Apps Store

This repository contains the Odoo 18 module package for `airiv_whatsapp_indonesia`.

Required store assets are maintained in:

```text
airiv_whatsapp_indonesia/static/description/
  icon.png
  banner.png
  index.html
```
