AIRIV Indonesia Communication Rail

Indonesia WhatsApp Business Messaging Engine

Automated WhatsApp notifications for sales orders, delivery resi, invoices, and Indonesian customer communication workflows inside Odoo 18 Community.

Odoo 18 Community Fonnte Gateway WAHA Sandbox LGPL-3 AIRIV

Core Capabilities

This module turns daily Odoo operations into structured WhatsApp communication with controlled templates, phone normalization, gateway routing, and audit evidence.

Gateway

Fonnte and WAHA ready

Use Fonnte Cloud REST API for production messaging or connect to WAHA for self-hosted WhatsApp HTTP delivery.

Sandbox

Safe simulation mode

Test message payloads, templates, merge fields, and audit logs without sending real messages or consuming API tokens.

Indonesia

Local phone sanitizer

Normalize local numbers such as 08xx and +62 formats into gateway-ready 628xx recipient numbers.

Feature & Workflow Automation

Sales

Order confirmation alerts

Send order summaries with customer name, order number, order total, carrier context, and payment link placeholders after sales confirmation.

Logistics

Delivery and resi updates

Send outgoing delivery notifications with courier, waybill number, and Biteship/RajaOngkir-style tracking URL context.

Accounting

Invoice and tax messaging

Send invoice alerts with amount, due date, invoice reference, and Faktur Pajak context when customer invoices are posted.

Installation Guidance

1

Install the module

Clone the repository on branch 18.0, add the module folder to your addons path, restart Odoo, and update the apps list.

2

Start in sandbox

Create or activate a gateway configuration in sandbox mode and confirm that templates generate correct message logs.

3

Enable production rails

After sandbox validation, add Fonnte or WAHA credentials and enable automation flags for sales, delivery, and invoice workflows.
