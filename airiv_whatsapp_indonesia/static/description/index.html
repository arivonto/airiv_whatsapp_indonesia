Indonesia WhatsApp Business Messaging Engine

Core Capabilities

This module turns daily Odoo operations into structured WhatsApp communication with controlled templates, phone normalization, gateway routing, and audit evidence.

Gateway

Fonnte and WAHA ready

Use Fonnte Cloud REST API for production messaging or connect to WAHA for self-hosted WhatsApp HTTP delivery.

Sandbox

Safe simulation mode

Test message payloads, templates, merge fields, and audit logs without sending real messages or consuming API tokens.

Indonesia

Local phone sanitizer

Normalize local numbers such as 08xx and +62 formats into gateway-ready 628xx recipient numbers.

Feature & Workflow Automation

1

Sales alerts

Send order summaries with customer name, order number, total amount, carrier context, and payment link placeholders.

2

Delivery alerts

Send outgoing delivery notifications with courier, waybill number, and tracking URL context.

3

Invoice alerts

Send invoice alerts with amount, due date, invoice reference, and Faktur Pajak context.

4

Sandbox QA

Test templates, placeholders, recipient resolution, and audit records without sending real WhatsApp messages.

Installation Guidance

Install

Add to Odoo addons

Clone branch 18.0, add the module folder to your addons path, restart Odoo, update the apps list, and install the module.

Configure

Start in sandbox

Create or activate a gateway configuration in sandbox mode and confirm that templates generate correct message logs.

Operate

Enable production rails

After sandbox validation, add Fonnte or WAHA credentials and enable automation flags for sales, delivery, and invoice workflows.

Configuration Checklist

GatewayCreate or activate one gateway configuration.
SandboxStart with sandbox mode and confirm message logs are generated correctly.
TemplatesReview default templates and adapt the wording to your company tone.
AutomationEnable automation flags gradually: Sales, Delivery, then Invoice.
ProductionMove to production gateway credentials only after sandbox results are correct.
